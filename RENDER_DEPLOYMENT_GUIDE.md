# CommitIQ Deployment Guide for Render Free Tier

This guide will walk you through deploying CommitIQ to Render's free tier securely.

## Prerequisites

1. A GitHub account with your CommitIQ repo
2. A Render account (sign up at [render.com](https://render.com))
3. A GitHub API token (for accessing GitHub data)

## Security Considerations

- All sensitive information will be stored as environment variables in Render
- The GitHub token and database credentials will not be committed to the repository
- The database will use a secure password that is auto-generated by Render

## Step 1: Prepare Your Repository

1. Ensure all sensitive information is removed from code and stored in environment variables
2. Commit the `render.yaml` Blueprint file to your repository
3. Push your repository to GitHub

## Step 2: Set Up Render Database Service

1. Log in to your Render dashboard
2. Click on "New" and select "PostgreSQL"
3. Configure your database:
   - Name: `commitiq-db`
   - Database: `github_data`
   - User: `commitiq`
   - Plan: Free
4. Click "Create Database"
5. Once created, note down the connection details (internal URL, host, etc.)

## Step 3: Deploy Backend Service

### Option 1: Manual Setup

1. In your Render dashboard, click "New" and select "Web Service"
2. Connect your GitHub repository
3. Configure the service:
   - Name: `commitiq-api`
   - Root Directory: `backend`
   - Environment: `Python`
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `hypercorn run:app --bind 0.0.0.0:$PORT`
   - Plan: Free
4. Add environment variables:
   - `FLASK_ENV`: `production`
   - `FLASK_APP`: `run.py`
   - `DB_HOST`: [Your Render DB host]
   - `DB_PORT`: [Your Render DB port]
   - `DB_NAME`: `github_data`
   - `DB_USER`: `commitiq`
   - `DB_PASSWORD`: [Your Render DB password]
   - `GITHUB_TOKEN`: [Your GitHub API token]
   - `EMAIL_HASH_PEPPER`: [Generate a secure random string]
   - `FRONTEND_URL`: `https://[your-frontend-service-name].onrender.com`
5. Click "Create Web Service"

### Option 2: Blueprint Deployment

1. In your Render dashboard, click "New" and select "Blueprint"
2. Connect your GitHub repository
3. Render will automatically detect the `render.yaml` file
4. Review the services configuration
5. Add any missing environment variables (especially `GITHUB_TOKEN`)
6. Click "Apply Blueprint"

## Step 4: Deploy Frontend Service

### Option 1: Manual Setup

1. In your Render dashboard, click "New" and select "Static Site"
2. Connect your GitHub repository
3. Configure the service:
   - Name: `commitiq-frontend`
   - Root Directory: `frontend`
   - Build Command: `npm install && npm run build`
   - Publish Directory: `build`
   - Plan: Free
4. Add environment variables:
   - `REACT_APP_API_URL`: `https://[your-backend-service-name].onrender.com/api`
5. Click "Create Static Site"

### Option 2: Blueprint Deployment

This will be automatically handled if you use the Blueprint approach in Step 3.

## Step 5: Update CORS Settings (if needed)

If you encounter CORS issues, ensure your backend code is properly configured to allow requests from your frontend domain.

In your Flask application setup (app/__init__.py or similar), ensure CORS is configured with the correct frontend URL:

```python
from flask_cors import CORS

# In your app creation function
CORS(app, origins=[os.environ.get('FRONTEND_URL')])
```

## Step 6: Verify Deployment

1. Once both services are deployed, visit your frontend URL
2. Test the application functionality
3. Check the Render logs for any errors

## Limitations of Render Free Tier

1. **Sleep after inactivity**: Free services will "sleep" after 15 minutes of inactivity
2. **Limited database storage**: 1GB storage limit
3. **Bandwidth limits**: 100GB/month
4. **CPU/Memory limits**: Limited resources for computation

## Troubleshooting

1. **Database Connection Issues**:
   - Check that the database credentials are correct in environment variables
   - Ensure your backend service has access to the database

2. **API Connection Issues**:
   - Verify the `REACT_APP_API_URL` is set correctly in the frontend service
   - Check CORS configuration in the backend

3. **GitHub API Rate Limiting**:
   - The free GitHub API has rate limits. Implement proper caching to minimize requests

## Maintenance

1. **Monitoring**: Regularly check Render logs for errors
2. **Database Backups**: Set up periodic database backups
3. **GitHub Token**: Rotate your GitHub token periodically for security
